# Contracts

Phase 2 adds `GameEscrow.sol` for Abstract testnet experiments only.

Current contract scope:

- Accept ERC-20 token deposits
- Track each player's available balance
- Allow each player to withdraw their own available balance

Not included yet:

- Match entry locking
- Prize settlement
- Admin withdrawals
- Mainnet deployment

High Stakes must stay locked until the escrow contract is deployed on testnet and gameplay is server-owned.
