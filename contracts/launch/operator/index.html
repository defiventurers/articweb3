Deploy or resume

The registry records gameplay commitments. The passport is an account-bound ERC-721 with updatable metadata.

This address receives proof registrar, passport minter and metadata roles. Automated backend operation needs a securely configured, funded operator key. For a local test rehearsal, the owner can also be the operator.

    Each pending transaction is saved on this browser as soon as its hash is returned. Keep the exported record to resume elsewhere.

    3

    Record a test rehearsal

    Register an explicitly labelled operator test, commit a future randomness request, and close a one-event checkpoint. This establishes receipt plumbing; an actual player match remains a separate acceptance check.

    A fresh rehearsal preserves previous receipts and uses a round after both the current client time and the chain timestamp. Existing contracts are reused.

    4

    Reconcile confirmed events

    Check both contracts from their creation blocks, wait for two L2 confirmations, and compare indexed passport mint events with the onchain total. Reorganised blocks are rechecked.

      Two L2 confirmations do not establish Ethereum finality. The browser stores this diagnostic index locally; the included backend worker provides durable database indexing after configuration.
