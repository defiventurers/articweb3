# Heritage Visual Refresh Prompts

## Catalogue master implementation prompt

> Redesign the heritage-game catalogue as **Tactile Expedition Theatre**. Keep Arctic Dominion unchanged. Give every heritage title a distinct, physical-feeling cover art treatment; make game discovery feel like browsing a premium board-game collection; and add calm, readable in-game polish without changing rules, board topology, modes, controls, ARIA labels, or hit targets. Use a deep midnight base, one game-specific accent, warm Lantern Coral only for decisive invitations, paper-fibre texture, a die-cut cover frame, archival numbering, and the recurring guide cast only outside source-native competitive roles. Avoid generic HTML-card layouts, purple gradients, fake rewards, streaks, scarcity, clutter over boards, visual changes that alter pointer layers, or unverified cultural costumes. All cover art must fail gracefully into a styled deterministic cover rather than a broken image.

## Cover-art generation contract

Create a **vertical 4:5 game-box cover illustration**. The cover must be painterly, tactile, premium, and suitable for a board-game library. Keep a generous dark, low-detail area in the upper third for a separately rendered HTML title. Use no readable words, no logo, no flags, no national costumes, no real people, no weapons, no UI controls, and no cultural claims beyond the supplied game motif. Use a matte paper texture, layered cut-paper depth, precise game-board geometry where specified, and one lantern-like warm accent. The asset is decorative only: it must not replace source-native playable pieces.
