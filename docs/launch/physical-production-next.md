# Physical collection — engineering progress and production brief

Nine locator-jig OpenSCAD sources and JSON board/starting-piece inventories are generated from the app by `node scripts/export-physical-layouts.mjs OUTPUT`. Units are millimetres. Source-native cell IDs and the current start positions are retained. Shanshui uses its source board adapter; Commander uses the approved 11×12 geometry constants. The jig has recessed circular locator marks, no protruding pegs. It does not yet engrave legal move routes, special terrain or palace/river boundaries, and is not a complete playing board.

## Continue from approved art

Search found the older `SanYouQi_450mm_Board_Engineering_Proof.pdf` and the board editor. No final STL/BLEND sculpt set was resolved. Do not replace the approved ski chariot, bases, snow-capped grey mountains, fortified walls or final four characters with generic printable pieces. Obtain/recover the actual sculpt source before declaring manufacturing-ready miniatures. Concept renders are not 3D meshes.

The geometry export exposes an important scale issue: at a 450mm field width, some San You Qi centres are only ~13.3mm apart and Sanguo Qi centres ~16.3mm apart. A 25–30mm collectible base will overlap those locations. Choose a larger board or carefully designed narrower pieces using measured physical samples. Do not move legal points to make a miniature fit. Each JSON includes nearest-centre distance and a conservative base-size estimate.

## Quote and sample package

Request separately: one complete pilot set, 10 sets, 25 sets, 50 sets; board substrates/tiles; detailed resin miniatures; support removal/washing/curing; primer/paint; packaging; GST; delivery; mould/master ownership; replacement policy. Ask for STL checks and exact print-volume limits before splitting boards. Compare delivered cost per accepted set, not only grams. Keep source sculpts and editable assembly files.

First pilot: San You Qi, continuing the approved ski chariot and terrain work. Check all 156 positions, 54 pieces, bases clearing neighbouring occupied points, spear/flag strength, warping, matched team colours, wall offset, removed/retained forts, and start-position layout. Then qualify one set per remaining game before batch orders.
