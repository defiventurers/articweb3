# Sat-gol source note

The project priority rulebook labels the source as Das Gupta 1926. The bibliographic record for *A Few Types of Sedentary Games Prevalent in the Central Provinces* is volume 20 of the *Journal and Proceedings of the Asiatic Society of Bengal*, published in 1924, pages 165–169. The implementation therefore uses 1924 in its ruleset IDs and source labels.

This correction changes only the citation year. It does not change the seven-circle opening, anticlockwise relay, immediate-beyond capture, forced-start ambiguity, mutual-agreement ending, or captured-stone scoring described in the recovered rule summary.
