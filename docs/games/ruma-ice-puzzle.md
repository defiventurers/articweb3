# Ruma Ice Puzzle — Tchuka Ruma

Ruleset: `tchuka-ruma-campbell-chavey-1995-1.0.0`

Source baseline: Paul J. Campbell and Darrah P. Chavey, “Tchuka Ruma Solitaire,” *The UMAP Journal* 16.4 (1995), pp. 343–365, describing the standard game from DeGrazia’s 1948 account.

## Core rules

- The classic puzzle has four ordinary pits followed by the Ruma.
- Each ordinary pit begins with two counters; the Ruma begins empty.
- Choose any non-empty ordinary pit and sow rightward one counter at a time.
- If counters remain after reaching the Ruma, wrap to the far-left pit and continue.
- If the last counter lands in a non-empty ordinary pit, lift that pit and continue the same move.
- If the last counter lands in the Ruma, the move ends safely and the next move may begin from any non-empty pit.
- If the last counter lands in an empty ordinary pit, the puzzle is lost.
- Win by moving every counter into the Ruma.

## Product modes

- classic four-pit, two-counter puzzle;
- guided chain lesson;
- five-pit challenge;
- exact local solver for hints;
- loop-state protection;
- responsive solo board.

The five-pit challenge is clearly labeled as a generalized puzzle configuration. It is not presented as the canonical 4×2 starting position.

Ruma Ice Puzzle is solo and does not create multiplayer rooms, wallet escrow, wagering, payouts or token rewards.
