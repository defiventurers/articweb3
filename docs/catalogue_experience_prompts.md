# Arctic Dominion: Experience Design Prompts for Every Game Page

## Product north star

Arctic Dominion should feel like a **small, collectible cabinet of welcoming winter table games**, not a database of rules. The experience should be calm enough for first-time learning, tactile enough to invite a move, and expressive enough that every successful choice feels acknowledged. The product must never manipulate the player through artificial scarcity, fake social proof, misleading reward mechanics, or friction that pressures play. “Addictive” is interpreted here as **deeply replayable through mastery, discovery, clean feedback, and delightful ritual**.

> **Universal execution brief.** Preserve all verified source rules, existing practice, local, drill, online, and How to Play modes. Use the current dark-ice visual language, readable high-contrast type, honest outcomes, large mobile touch targets, reduced-motion support, and a clear next action. Never block a legal move behind decoration. Every animation should confirm a real action in 120–260 ms; no autoplaying decision or false reward is permitted.

## Page prompt kit

The following prompts apply to the corresponding page in **every** game. Combine each with the game-specific prompt in the catalogue matrix below.

| Page | Executable design prompt |
|---|---|
| **Cover / landing** | “Create an inviting portrait of a traditional winter table game. Show the real board topology at generous scale with two to four tactile tokens, preserve a quiet text-safe zone, and use one crisp promise about the tension of the game. Add a single prominent ‘Enter’ action and a secondary return path. Establish the game’s personality through material, route, and mascot motifs rather than generic gradients.” |
| **Mode menu** | “Turn the game choices into a friendly decision shelf. Explain the difference between practice, local, drill, online, and rules in one short benefit line each. Make the recommended first path obvious without hiding any option. Use direct labels, calm status chips, 48 px minimum touch targets, and a visible escape back to the cover.” |
| **Live board** | “Present the real board as the hero. Place turn ownership, the single next legal action, and one concise strategic hint near the board without competing with it. Render legal moves as a distinct ice-light state, selected pieces as a stable tactile state, and invalid choices as a gentle explanation rather than a silent failure. Keep counters large, physical, and accessible by both color and text.” |
| **Rules / How to Play** | “Teach with a short, sequenced playable story: objective, first move, special rule, win condition. Separate historical provenance from gameplay instructions. Use the authentic board map, clear examples, and a ‘Try the teaching mode’ action. Avoid rule walls; every sentence should answer a player question.” |
| **Results / completed state** | “Celebrate the confirmed result honestly. Show what decisive condition occurred, one memorable move or rule, and two clear next choices: replay the same challenge or return to modes. Use warm light and a short physical settling animation, not confetti or exaggerated claims.” |
| **Online / room state** | “Make waiting legible and low-pressure. State the room’s privacy, opponent status, turn order, and expected next action. Show a graceful local/practice alternative while waiting. Do not imply that an opponent is available unless a real room or match is present.” |

## Execution priorities

The first implementation pass should improve all games through shared experience infrastructure rather than altering twenty independent rule engines. It should create consistent focus, touch, legal-move, selected-piece, action-feedback, reduced-motion, menu-card, and results affordances; then layer the most useful game-specific teaching/board clarity cues on top. The current asset-repair fallback remains mandatory so no delight enhancement can regress into broken visual UI.

## Acceptance checklist

| Requirement | Evidence |
|---|---|
| Every game has a page-level design prompt | The universal six-page kit plus all twenty game modifiers above. |
| Rules and existing modes remain preserved | No change to rules modules or mode routing; all smoke tests remain green. |
| Experience is inviting but responsible | No fake reviews, false availability, loot mechanics, artificial countdowns, or coercive prompts. |
| Mobile-first interaction is improved | Large tap targets, visible focus, legal-state clarity, and reduced-motion support are applied to shared controls. |
| Users can learn and replay quickly | Every screen retains a clear next action, return path, and drill/practice route. |
