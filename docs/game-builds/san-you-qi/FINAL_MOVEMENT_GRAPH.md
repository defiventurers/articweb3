## Implementation rule

The board is an explicit graph. Nearby points are not automatically connected.

Movement legality is determined by:

1. the arm lines;
2. the continuation lines above;
3. the six added central horizontal lines;
4. the piece's movement geometry;
5. terrain restrictions;
6. faction-oriented forward direction;
7. faction-specific enemy territory / promotion state;
8. blockers and capture rules.

The exact C-point graph is the finalized Arctic Dominion reconstruction, not a claim that these node labels appear in the surviving Qing text.
