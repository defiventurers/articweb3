# Antarctic Kingdoms 5.7.1 — Cờ Tư Lệnh Android integration

**Status: source prepared, not built/signed/installed/deployed.** This is a *modern Vietnamese game* devised by Nguyễn Quý Hải circa 2010, shown in an independent Antarctic Kingdoms fantasy visual adaptation; do not call it ancient.

## Outcome
- Android native application keeps the existing `xyz.arcticdominion.play` package identity. Version set to **5.7.1**, Android **versionCode 80** (previous 5.7.0 code 79).
- Adds a **separate Cờ Tư Lệnh card** below Shanshui on the Games page. No change to existing seven-hall IDs, unlocks, wallets, or other game engines.
- Uses `CoTuLenhMobile` to embed the same React practice app, authoritative rules engine and room protocol as the website, with local pass-and-play, practice, Easy/Medium/Hard bots and separate private rooms.
- Builds the 11-column × 12-row board and **22 red/blue transparent WebP cutouts** into the APK `art/co-tu-lenh/` hierarchy; includes the v0.3 rules-profiles JSON.
- Keeps the optional defensive coverage rings (red/blue; AA and Navy radius 1, Missile 2 straight/1 diagonal) and existing rotation, zoom, highlights and guided How to Play.
- New game uses `wss://articweb3.onrender.com` for `ctl_*` room messages, with browser invitation links to `https://arcticdominion.xyz/?game=co-tu-lenh&room=...`. Actual service compatibility and live room flows need device testing.
- Bundle builder still authenticates original 5.6.8 baseline SHA-256 to preserve released assets, now adds artwork additively to the game-assets preload manifest.
- Original signature is mandatory: build script refuses to create an install-over APK without the release keystore/password.

## Source build
From a complete repository checkout with `mobile/arctic-play/build-deps/node_modules` installed, an official Android SDK, Java compiler (or ECJ), and **original** signing keystore/password in a secret location:

```bash
cd mobile/arctic-play
npm run test:co-tu-lenh
npm run build -- --baseline-apk /secure/path/AntarcticKingdoms-v5.6.8.apk
python3 scripts/build-apk.py \
  --sdk /path/to/android-sdk \
  --jdk /path/to/jdk \
  --keystore /secure/path/ArcticPlay-release.jks \
  --password-file /secure/path/signing-password.txt \
  --output /secure/builds
```
Only after `apksigner verify` succeeds, inspect `AntarcticKingdoms-v5.7.1.apk`, install over 5.7.0, then test sign-in, asset loading, 11×12 board hit targets, all 11 roles and both factions, rules profiles, rings, rotation, local/bots/tutorial, reconnect and online private room action rejection on an Android phone.

## Limitations and release gates
1. **No APK built or uploaded** from this development environment. The original signing material, Android SDK, complete dependency tree and native test device are absent; only source-level integration is present.
2. The game's full original starting arrangement and two ford columns are still source-unverified. Advanced multi-action carrier sequences, air interception ordering, tournament scores and some HQ rules remain research-grade. Maintain conspicuous **Research Draft** label.
3. Original Vietnamese gameplay and fantasy piece artwork have separate provenance. Verify any current commercial digital-adaptation license before distribution; this source update is not permission to market a paid game.
4. Do not change the live update feed to v5.7.1, and do not assert server or mainnet deployment, until the signed APK and compatible backend have passed release gates.
5. Retain all existing supported play modes; keep all chain/wallet changes out of this update.

## Acceptance criteria
- Mobile source builds without unresolved imports; all 22 asset paths exist, decode and preload on sign-in.
- 7 legacy halls plus Shanshui still appear and function; Commander Chess card opens its own game on Android.
- 36 focused Cờ Tư Lệnh rules and service tests plus mobile integration and existing Android smoke tests pass.
- The generated Android APK is signed by the **same certificate** as the installed 5.7.0 package, bears versionCode 80 and can upgrade without losing access or saved data.
- Release feed only updated after an actual signed file has passed package verification and Android device smoke tests.
