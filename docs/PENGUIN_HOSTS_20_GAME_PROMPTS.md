# Four Penguin Hosts: 20 Heritage-Game Implementation Prompts

## Shared master prompt

> Apply the Four Penguin Hosts as friendly, non-competitive heritage-game guides: Polly Clan (pink, welcoming), Retsba Legion (red, focused and kind), Pengu Order (blue, calm), and Abster Tribe (green, patient). Place them only on catalogue covers, entry pages, How to Play, Field guides, practice nudges, or result-side decoration. Never place them inside a board cell or replace a historical animal, card, stone, cowrie, fish, token, or player counter. Preserve rules, board geometry, modes, accessibility, and Arctic Dominion. Use a tactile arctic board-game-box look with each game’s own native geometry and high-contrast text.
