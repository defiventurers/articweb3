# Overall Heritage Game Experience Prompt

## Prompt

> Refine every individual Arctic heritage game into a warm, tactile digital board-game room for first-time visitors and returning players. Preserve the verified traditional rules, board topology, pieces, practice drills, local play, online routes, and all existing content. Do not alter the Arctic Dominion shell.
>
> Let the board remain the visual authority. Use each game’s existing material language—engraved ice rails, hand-painted cards, polished stones, seed pits, cowries, or carved counters—to create a calm but playful sense of place. Give the cover a readable invitation, the mode menu a confident next step, the active board a clear turn and legal-action hierarchy, the rules a scannable learning route, and results a satisfying but non-coercive rematch moment.
>
> Build replay appeal through clarity, tactility, gentle surprise, fast recovery, and visible mastery rather than urgency, fake scarcity, or manipulative reward loops. Include a quiet field-guide cue, keyboard-visible focus, reduced-motion support, safe touch targets, and optional feedback sounds that obey the global mute preference. Decorative layers must never block board cells, pieces, or buttons.

## Executed design contract

| Area | Applied to every heritage game |
|---|---|
| **Cover and menu** | Preserve each game’s material colour temperature while adding clearer invitation, stronger primary-action emphasis, and lightweight mode-orientation copy. |
| **Live board** | Keep source-correct geometry untouched; reinforce legal, selected, and turn states with high-contrast tactile highlights only. |
| **Learning** | Offer an optional Field guide with a context-aware first action, drill, or practice recommendation. |
| **Feedback** | Use optional low-volume selection, move, roll, confirmation, and guidance cues through the existing mute-aware sound manager. |
| **Return loop** | Keep result and restart actions direct, warm, and immediately reachable—without reward pressure or interruption. |
| **Accessibility and safety** | Preserve keyboard focus, reduced-motion behavior, screen-reader labels, responsive touch affordances, and pointer-safe decorative layers. |

## Acceptance criteria

The implementation succeeds only if all twenty heritage games retain their existing modes and rules, every board remains interactive at desktop and mobile sizes, the Arctic Dominion shell is unmodified, sound feedback is fully optional, and the complete serial smoke suite passes.
