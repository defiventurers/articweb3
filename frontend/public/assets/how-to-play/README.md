# Frost Academy image slots

Upload the five How To Play images into this folder with these exact filenames:

- `retsba-kingdom.png` — red team splash image
- `pengu-kingdom.png` — blue team splash image
- `abster-kingdom.png` — green team splash image
- `polly-kingdom.png` — pink team splash image
- `dominion-pieces-roster.png` — full Dominion pieces roster image

The How To Play screen already has emoji fallbacks, so the app will still render before these images are uploaded.
