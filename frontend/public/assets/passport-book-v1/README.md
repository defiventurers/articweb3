# Lantern and Crown passport stamps

New raster artwork requested for the Passport redesign, generated with the built-in image tool. Existing approved mascot identity and art are unchanged.

| File | Use |
| --- | --- |
| lantern-stamp.webp | Earned founding-hall lantern, with native game name and original date |
| crown-stamp.webp | Cosmetic Antarctic Crown after all seven existing lantern milestones; a muted preview is labelled unearned |

Both are 512 × 512 RGBA WebP derivatives of the 1254 × 1254 transparent PNG masters. Optimization only resized/encoded the generated images. Original masters and these optimized files are included in the delivered stamp asset archive. Native code provides all labels, dates, controls and reward logic. No dates or words are baked into the artwork.

Prompt set: one face-on, isolated expedition passport seal with a warm nautical lantern, icy roof/crystals, concentric navy-teal engraved rings, snowflakes and antique-gold details; one matching prestigious crown seal with ice-crystal peaks, gold trim, a small Antarctic mountain crest and seven border stars. Rough ink edges, storybook engraving, transparent outside the seal, ivory inside, readable silhouettes at small size. No lettering, characters, logos, watermark, drop shadow or background scene. The lantern was the crown's style reference.
