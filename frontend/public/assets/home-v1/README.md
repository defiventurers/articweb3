# Approved Home artwork

User-approved Home redesign integrated in Antarctic Kingdoms v5.9.4.

`home-harbor-day.webp` and `home-harbor-night.webp` are the hero backgrounds. `home-hosts-welcome.webp` contains Nova, Retsba, Pengu and Abster. The Learn, friends, physical-board concept, Passport, hall and maker-logo images support their corresponding native buttons. `resume-yanyi.webp` is retained from the approved concept pack; live Continue uses the actual saved game's cover and does not assume a Yan Yi save.

These files are derived from the approved Home asset pack, with no character redesign in this implementation. They are copied to `art/home-v1/` and registered in the public artwork preload manifest.
