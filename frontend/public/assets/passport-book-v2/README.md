# Passport runtime art v2

Seven distinct lanterns plus the replacement gold company cover. The Crown remains in `passport-book-v1/crown-stamp.webp`.

The cover is a DRAFT gold interpretation of the existing company mountain/star mark, created with built-in image generation. It contains no lantern. Character artwork is unchanged.

Names, earned dates and time zones are native text, supplied from the player's existing milestone. Do not bake a fixed date into the app. Named PNG/SVG exports contain clearly labelled dynamic-date placeholders. See `mobile/arctic-play/PASSPORT_BOOK_V596.md` for sources, period limits, source boundary and validation.
