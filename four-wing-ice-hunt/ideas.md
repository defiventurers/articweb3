# Four-Wing Ice Hunt — Reference Fidelity Brief

## Ground-Truth Reference

The supplied game screen is the visual authority for this rebuild. Preserve its dark Arctic-navy interface, thin aqua-lit rounded outer panel, restrained metallic outlines, centred premium headline, pale serif display typography, turquoise action buttons, and compact desktop game-lobby composition. The experience should continue to feel like a polished strategy-game launcher rather than a generic landing page.

## Design Philosophy

The interface uses an **Arctic heritage-console** aesthetic: a deep blue night surface, frosted cyan highlights, and crisp high-contrast typography convey a premium historical strategy game. UI components have carefully measured rounded corners, hairline luminous borders, subtle inset shadows, and a small amount of visual texture. The hierarchy remains: eyebrow label, game title, one-sentence game premise, primary mode button, supporting mode buttons, then the heritage/rules note.

## Required Preservation

Keep the existing lobby features and their conceptual hierarchy: Online Multiplayer, Practice as Snow Leopards, Practice as the Colony, Local Two Player, and How to Play. Preserve the existing visual language rather than replacing it with a fantasy illustration, a dashboard, or a radically new layout.

## Allowed Change

The **How to Play** content is the only substantive rules change. It must use the finalised Four-Wing Hunt rule set: two snow leopards, twenty-four penguin colonisers, eight initial penguins, sixteen reserve penguins, progressive deployment alternating with a leopard turn, legal movement on connected intersections only, mandatory continuing capture sequences when available, a 12-or-more penguin capture victory for the leopards, and a victory for the colony when both leopards are immobilised.

## Signature Elements

- Icy turquoise primary call-to-action with dark navy text.
- Cool cyan outline controls with deliberate pressed and hover states.
- A small uppercase mint eyebrow label.
- Pale ice-white high-contrast serif title with balanced two-line wrap.
- A compact rule-note panel with a warm ice-gold left edge.

## Interaction Philosophy

Buttons should feel responsive and game-like: a short rise/glow on hover and a slight press on activation. The How to Play button opens an accessible rules overlay or dedicated rules view without removing the rest of the game modes. Gameplay mode controls remain usable and clearly separated from the documentation flow.

## Typography System

Use a sculptural high-contrast serif for the title, a technical monospaced uppercase face for the eyebrow and buttons, and a clean rounded sans serif for game explanations. Avoid Inter as the primary identity font.

## Brand Voice

The voice is concise, strategic, and atmospheric. Headlines should state the tactical premise directly; supporting copy should explain decisions in plain language without pseudo-historical claims. Example: “Deploy the colony. Seal every escape.”
