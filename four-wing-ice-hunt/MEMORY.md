# Memory: Four-Wing Ice Hunt

## Source features retained

The original project contains a menu with Online Multiplayer, Practice as Snow Leopards, Practice as the Colony, Local Two Player, and How to Play. It uses a line-graph board with a central lattice and four wing extensions. It also contains a compact practice bot and online room-code UI.

## Rules changes required

Replace the old Parker sequence and all-cattle victory wording. The new standard rule set starts with two snow leopards on opposite outer-wing starts, eight penguin colonisers on the central setup pattern, and sixteen colony reserves. Deployment alternates one colony placement with one leopard turn. Leopard victory occurs at twelve or more captured penguins. Colony victory requires both leopards to have no legal move or capture. A multi-capture sequence must continue while a legal capture remains.

The supplied screenshot, not a new art direction, controls the lobby: dark navy background, rounded cyan-outline card, mint eyebrow, pale serif title, turquoise primary action, four outlined supporting actions, and a gold-edged rule note. Do not replace this feature set or visual language.
