# Artic Web3

A Web3-first multiplayer lobby MVP for the Arctic Dominion / Chaturanga game.

## First milestone

- Cover page
- Main menu
- Profile creation
- AGW wallet connection
- Public and private rooms
- Four-player waiting room
- Five-second countdown

## Project folders

- `frontend`: React app
- `server`: realtime lobby server
- `shared`: shared game rules later
- `contracts`: Abstract contracts later
